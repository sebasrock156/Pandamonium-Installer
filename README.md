## Presentación
Este es otro Script Instalador de ArchLinux impulsado por medio de **GUM**, base inicial para el (*posible*) desarrollo de un respin (*que tenía planificado hace años*).

## Características
- Soporte x86_64 en BIOS y UEFI (De momento).
- Detección automática de conexión a internet (Cable o Wi-Fi).
- Sistema de particionado (*más o menos intuitivo*), formateo y montaje automático de unidades de almacenamiento.
- Posibilidad *"nativa"* de usar ZFS y crear ZPools.
- Selector dinámico de Kernel y Sistema de Inicio (*Init*) entre Systemd (*clásico*) u OpenRC (*Artix*) (De momento).
- Creación interactiva y simple en la creación de usuarios y configuración del sistema (Chroot).
- Posibilidad de reforzar la seguridad del sistema desde la instalación (con *AppArmor* o *SELinux*. **NOTA: Requiere del kernel *linux-hardened* o del kernel *mainline* y sus respectivos *linux-headers*.**)
- Selección de diferentes bootloaders (*GRUB*, *systemd-boot* y *EFISTUB*).
- Una selección variada de Entornos de Escritorio y Gestores de Ventanas.
- Una extensa sección de paquetes extra que abarcan desde herramientas para facilitar la compilación/instalación de paquetes AUR, hasta introducir entornos de virtualización.
